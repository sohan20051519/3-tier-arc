# Task Manager Frontend

React + Vite single page application for the 3-tier Task Manager.

## Features

- Clean Task Creation Form
- Real-time Task List with completion status toggle
- Task Deletion
- System Health and Architecture Status indicators
- Responsive UI styled with Tailwind CSS

## Environment Variables

- `VITE_API_URL` - URL of the Express backend API (e.g. `http://localhost:5000` or empty when using Nginx reverse proxy).

## Development

```bash
npm install
npm run dev
```

## Production Build

```bash
npm run build
```
